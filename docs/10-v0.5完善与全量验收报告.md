## 3. 生产化加固

### 3.1 环境变量开关（全部可选，默认关闭）

| 变量 | 默认 | 作用 |
|---|---|---|
| `EPISTEME_AUTH_MODE` | `legacy` | `secure` 时启用鉴权中间件 |
| `EPISTEME_AUTH_SECRET` | 空 | HS256 JWT 与 HMAC 签名密钥（secure 必填） |
| `EPISTEME_API_KEYS` | 空 | `keyId:role` 列表，绑定 API Key 与角色 |
| `EPISTEME_DB_PROVIDER` | `sqlite` | `postgres` 时切到 Npgsql |
| `EPISTEME_PG_CONNECTION` | 空 | PostgreSQL 连接串 |
| `EPISTEME_RATE_LIMIT` | `600` | 固定窗口每分钟许可数 |
| `EPISTEME_SIGNATURE_SKEW` | `300` | 时间戳 / Nonce 有效期（秒） |
| `EPISTEME_FETCH_WORKER_URL` | compose 内网 | 独立 worker 地址 |
| `EPISTEME_FETCH_TOKEN` / `EPISTEME_FETCH_ALLOWLIST` | 空 | worker 认证与域名白名单 |

### 3.2 secure 模式

- Bearer **JWT HS256**：校验 alg / 签名 / exp / role；角色透传给 `RequireRole`。
- **API Key + HMAC-SHA256**：canonical string = `method\npath\nquery\ntimestamp\nnonce\nrole\nbodyHash`；`X-Episteme-*` 头。
- **Nonce 单次使用**（`ConcurrentDictionary` + 窗口清理），重放返回 `409 NONCE_REPLAYED`。
- **固定窗口限流**：`GlobalLimiter` 挂在 `/api/` 与 `/mcp` 分支，超限 `429 RATE_LIMITED`。
- `/health` 与 `GET /capabilities` 保持公开，便于探活。

### 3.3 数据库与传输

- `EpistemeDbContext` 对全部 `DateTime` 属性加 `ValueConverter` 统一 UTC，解决 Npgsql `timestamp with time zone` 只接受 UTC 而 SQLite 读回 `Unspecified` 的差异；已用真实 PostgreSQL 17 容器验证。
- Compose 新增 `fetch-worker`（仅 `expose: 8090`）与 `--profile postgres` 可选数据库；`restart: "no"` 保持不自启。
- MCP 三传输：`POST /mcp`（主）、`GET /mcp/sse` + `POST /mcp/messages?sessionId=...`（共享 `ProcessAsync`）、`src/Episteme.McpStdio`（一行请求 / 一行响应转发到 HTTP MCP，诊断只写 stderr）。

## 5. 功能打磨与排错：本轮修复清单

回归不是走过场，本轮实际发现并修掉 11 个问题，其中 5 个是**产品缺陷**：

| # | 类型 | 问题 | 修复 |
|---|---|---|---|
| 1 | 测试 | MCP `fetch_web` 用 9 字符 HTML 片段，低于 Readability `charThreshold=60`，诚实走了 fallback 被误判失败 | 用例改用完整长快照；保留 fallback 语义 |
| 2 | 测试 | SSE 辅助函数调用 `HTTPResponse.settimeout()`（不存在） | 改为对底层 socket 设超时 |
| 3 | 测试 | `import http.client` 遮蔽模块级 `http()` 请求辅助函数 | 别名导入 `http.client as hc` |
| 4 | **产品** | **Web UI 没有空间切换器**：`loadSpaces()` 永远选 `spaces[0]`（创建时间最早），且已有空间后无法再新建 | 顶栏新增 `#space-select` + 「+ 空间」常驻入口与内联表单；`loadSpaces(preferredId)` 保留当前选择；`createSpace()` 自动切到新空间；`switchSpace()` 隔离阅读器/版本状态 |
| 5 | 测试 | `commits?limit=30` 有上限，日志满 30 条后「数量增长」断言假失败；同一脏库连跑两轮又引发 Pack 重复安装 | 断言改用 `headCommitId`；UI 回归始终自建专属空间，脏库也可确定性运行 |
| 6 | **产品** | 客户端 `Episteme.Client.Probe` 局部变量 `commits` 与外层重名（`CS0136`） | 改名 `commits3` |
| 7 | **产品** | 桌面 `UpdateDocumentAsync` 用 `PUT`，后端是 `PATCH /documents/{id}` → HTTP 405 | 增加 `Patch` helper 并对齐动词 |
| 8 | **产品** | Probe 复用同一 `JsonObject anchor` 挂到两个请求体，`JsonNode` 抛 `The node already has a parent` | 第二处用 `DeepClone()` |
| 9 | 测试 | 桌面离线抓取仍用 `<article>` 片段，Readability 需要完整文档（head/title/body） | 改为完整 HTML 文档 |
| 10 | **产品** | secure 模式注册了**命名**限流策略却未挂到端点，`UseRateLimiter()` 实际不生效，429 永不出现 | 用 `options.GlobalLimiter = PartitionedRateLimiter.Create(...)` 挂同一固定窗口 |
| 11 | 工具 | 宿主机无 dotnet、SDK 镜像无 python，stdio 回归无法执行；另新增的 PostgreSQL 脚本 URL 重复拼接 BASE | `stdio_smoke.py` 支持 `EPISTEME_DOTNET_CMD`；修正 `http()` 绝对/相对地址判定 |

**Readability 的诚实行为**：短片段 / 无完整文档时 worker 返回 `extractor=readability-fallback`，不伪装成成功。这是设计取舍，不是缺陷。

## 7. 诚实边界（未做到 / 未验证）

1. **Android 完全未动**：`src/Episteme.Android/` 未编译 APK、未真机验证；本轮按用户要求跳过。
2. **桌面 GUI 未实际开窗**：容器内无 X server；只验证了共享 ViewModel / REST / MCP 客户端与编译。
3. **SSE 会话只在单进程内存**：多实例部署需共享背板（Redis 等），当前未接。
4. **未接 Redis / MinIO / 对象存储 / 密钥托管 / 审计归档**：仍为单机 SQLite（或可选 PostgreSQL）。
5. **在线抓取未对公网验证**：回归使用离线 `/extract` 快照；`/fetch` 的 SSRF 防护已单元覆盖，但真实 DNS / 出网策略需在受控环境复验。
6. **secure 模式是最小实现**：JWT 无 issuer / audience / 刷新 / 撤销列表；限流是全局固定窗口而非按用户分区；无 TLS 终止、无 WAF。
7. **MCP 为自实现最小 JSON-RPC**，未使用官方 MCP SDK；stdio 是 HTTP 转发 bridge，不是进程内 Server。
8. **PDF 文本层仍保留**：旧 `\f` 文本层 Part 继续以 pdf.js 之外的兼容模式显示；新上传 PDF 走 canvas。
9. **Monaco / pdf.js 失败即降级**：渐进增强是有意为之，不等于所有浏览器都有同等功能。
10. **GitHub**：本地 v0.4 `b0d25a9` 与本次 v0.5 提交需用户重新提供凭证或配置 SSH 后才能推送；远端 `origin/main` 停留在本轮提交前。
