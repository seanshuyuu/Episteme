已实现

  • 领域模型：ApplicationUser、Workspace、WorkspaceMember，包括工作空间类型、状态、Owner/Editor/Reader 角色和关键状态变更规则。
  • 数据访问骨架：EF Core DbContext、Identity 用户/角色映射、OpenIddict EF Core 持久化模型注册，以及 Npgsql PostgreSQL 配置。
  • 共享授权用例：集中校验 OAuth scope、用户状态、工作空间状态、成员资格和工作空间角色；仓库查询一次性取回授权快照。
  • Web API：GET /api/v1/workspaces/{workspaceId}，要求 Bearer JWT 与读取 scope，并返回工作空间元数据。
  • Refit 客户端：提供强类型 API 接口和客户端依赖注入注册。
  • 自动化测试：覆盖基础领域约束、缺少 scope、非成员访问、Reader 写权限拒绝、管理员授权边界、空间归档和停用用户。
